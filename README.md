# ♟️ Chess — Play With Stockfish 19

A browser-based chess application built with JavaScript, featuring an interactive chessboard and Stockfish 19 chess engine integration.

## ✨ Features

- Interactive chessboard.
- Chess gameplay with legal move handling.
- Stockfish 19 chess engine integration.
- Custom chess pieces and board themes.
- Responsive user interface.
- Local chess engine execution.

## 🛠️ Technologies Used

- **HTML5** – Application structure.
- **CSS3** – Styling and layout.
- **JavaScript** – Game logic and functionality.
- **p5.js** – Graphics and rendering.
- **chess.js** – Chess rules and move validation.
- **Stockfish 19** – Chess engine.

## 📁 Project Structure

```text
Chess---Play-With-Stockfish19/
```

## 🚀 Getting Started

### Prerequisites

- Node.js and npm
- A modern web browser
- Stockfish 19 executable

### Installation

1. Clone the repository:

```bash
git clone https://github.com/bexxl/Chess---Play-With-Stockfish19.git
```

2. Navigate to the project directory:

```bash
cd Chess---Play-With-Stockfish19
```

3. Install dependencies:

```bash
npm install
```

### Running the Application

Start the local server using the command configured in `package.json`.

If no start script is configured, check `server.js` for the appropriate command.

Open the local address printed by your server in your browser.

## 🎯 Project Goal

The goal of this project is to build an interactive chess application that combines web development with chess programming and engine integration.

It also serves as a learning project for JavaScript, frontend development, chess logic, and working with chess engines.
